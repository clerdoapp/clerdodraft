# Changelog

## 0.5.0
- About 150 shapes, 52 diagram layouts, 20 chart kinds and 2,300 icons
- Glow, reflection, gradient fill and outline color for text; 12 text art styles
- 41 templates, including an Arabic letter
- Spelling in Arabic, French, Spanish, Portuguese, Dutch and Russian; hyphenation in 21 languages
- Interface in Arabic
- Digital signatures: sign and check
- Work together live, device to device; share links
- Embed any file; spreadsheets, documents and presentations stay editable in other apps
- Restricted editing by paragraph, comment reactions
- Mail merge from spreadsheets, contacts and data files
- `.doc` opens with formatting and pictures, `.pdf` opens with pictures
- EMF and WMF pictures are drawn on the page
- Share as a link hands over the file when the document is too large for a link
- Pictures from a web address, drawing on pictures, saved text keeps formatting
- Floating grouped drawings drawn in place, tracked formatting marked on the page
- Fixed: names with non-Latin letters in certificates

## 0.4.0
- More than 400 fonts: 212 open families, and common document font names drawn with matching open fonts
- The desktop app lists every font installed on the computer
- Searchable font menu grouped by kind
- Symbol and dingbat fonts show the right characters

## 0.3.0
- Equations drawn on the page, with an editor and structured save
- Diagrams, and grouped drawings drawn from files
- Mail merge preview in the document, merge rules, label sheets
- Column balancing, turned text in cells, pages side by side
- Picture crop and adjustments, fill-in fields, saved text, text from a file
- Fit, even out and split tables; format copy now includes paragraphs
- Six more templates and a keyboard shortcut list

## 0.2.0
- Word book with meanings and similar words, offline
- Automatic and optional hyphens
- Document themes and spacing presets
- Opens `.doc`, `.odt`, `.rtf`, `.pdf`, `.md`, `.html` and `.txt`; exports `.odt` and `.rtf`
- Password-protected files
- Version history, split view, new window, gridlines
- Focus reader, comment filters, translation where the system offers it
- Emoji, pen drawing, online video links, screenshots, text art, large first letters
- Table formulas, numbering restarts, custom bullets
- Facing pages, text aligned on the page, table of authorities, five citation styles, tracked formatting
- Fixed: a word could be lost after a very long word was split across lines

## 0.1.1
- Mac installer builds on a supported system
