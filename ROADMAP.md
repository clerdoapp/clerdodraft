# Roadmap

Priorities for ClerdoDraft. [docs/FEATURES.md](docs/FEATURES.md) lists what exists today, and [docs/gaps.md](docs/gaps.md) lists the known gaps in detail.

## Next
- Test on real Windows, macOS and iPad hardware and fix what turns up
- Round-trip testing against a wide set of real-world documents
- Code signing for Windows and macOS

## Later
- Interface in more languages
- Spelling for more languages

## Left out on purpose
- Scripting languages tied to one vendor, and their form controls
- Vendor cloud assistants and account services
