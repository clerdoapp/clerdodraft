# ClerdoDraft feature checklist

Runs on Windows, macOS and Linux, and as a web app that installs on iPad and works offline. On touch screens, tap to type, press and hold to select a word, and drag to extend it.

Status: `done`, `basic` (works, needs depth), `next` (not built).

## Files
- done: open and save .docx, keep unknown content on save, drag a file in to open, recovery copy on this device
- done: print and save as PDF, export web page, Markdown, plain text, document details
- basic: templates (4)
- next: .doc, .odt, .rtf, .pdf import; password-encrypted files; digital signatures

## Text and paragraphs
- done: fonts, sizes, bold, italic, underlines, strike, super and subscript, capitals, color, marker, letter spacing, hidden text, clear formatting, change case, copy formatting
- done: autocorrect, smart quotes, automatic lists and links while typing
- done: alignment, indents, line and paragraph spacing, keep with next, keep lines, page break before, single-line control, tabs with leaders, shading, borders, right-to-left
- done: bulleted, numbered and multilevel lists; styles: apply, edit, create; contextual spacing
- basic: format copy applies text formatting only
- done: ruler with indents, margins and tab stops
- done: paragraph border settings, cell color and border settings
- next: list restart and custom bullets, drop caps, text effects, style sets and themes, hyphenation

## Objects
- done: column width from the ruler; picture settings, wrap, rotate, drag floating pictures
- done: tables: rows, columns, merge, split, header rows, sort, text conversion, table styles, nested tables; pictures: insert, paste, resize, alt text on import; links; bookmarks; date and time; checkbox; symbols
- done: charts (columns, bars, line, area, pie, ring) with a data editor, saved with their numbers; text boxes; 13 shapes with fill and outline; imported diagrams are drawn and kept
- basic: grouped drawings stay in the file but show as a placeholder; floating pictures with wrap (import, layout); equations (text form, kept intact from imported files); cover page; watermark (app only)
- next: creating diagrams, word art, drawing with a pen, audio and video, embedded objects, screenshots, table formula fields

## Page
- done: size, direction, margins, columns, section breaks, page color, page border, line numbers, headers, footers, first and odd/even pages, page numbers
- next: column balancing, facing pages, vertical alignment in layout, text direction in cells

## References
- done: contents with refresh, footnotes, endnotes, captions, sources, citations, bibliography, cross-references, table of figures, index
- next: more citation styles, table of authorities

## Review
- done: track changes, accept and reject, changes list, comments with replies and resolve, compare two documents, word count, markup views, read-only mode, accessibility check, read aloud, dictation (where the browser supports it)
- done: spelling (US and UK English, offline), grammar rules for English, Arabic punctuation spacing, readability, personal dictionary, right-click fixes
- next: Arabic spelling dictionary, thesaurus, translation, language settings, restricted editing by section, formatting changes tracked, comment reactions

## Mail
- done: merge from .csv, fields, merge to a new file, envelopes, labels
- basic: preview by finishing the merge
- next: inline merge preview, printed-label sizes, merge rules

## View
- done: page view, reading view, outline panel with level changes, zoom, formatting marks, dark mode, command search
- done: web view and draft view
- next: side-by-side and split windows, gridlines

## Together
- next: live co-editing, share links, version history

## Left out on purpose
- Macro and scripting languages tied to one vendor, and their form controls
- Vendor cloud assistant and vendor account services
