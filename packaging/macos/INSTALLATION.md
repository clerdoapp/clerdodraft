# Installing on macOS

Download `clerdodraft-<version>-mac-universal.dmg`, open it and drag **ClerdoDraft** to
**Applications**. One file runs on both Apple-chip and Intel Macs.

The builds aren't code-signed yet. The first time, right-click the app, choose **Open**, then
**Open** again. After that it opens normally.

To make ClerdoDraft open `.docx` files by default: select a `.docx` file in Finder, choose
**File › Get Info**, pick ClerdoDraft under **Open with**, then **Change All…**.
